## Vercel 배포

1. 이 폴더 안의 파일 14개를 전부 GitHub 저장소 맨 위에 올려요 (사진 `photo-*.jpg` 4개도 꼭 함께).
2. Vercel이 자동으로 다시 배포해요. 새 저장소라면 **Add New → Project**로 가져와서 **Deploy**를 눌러요.
