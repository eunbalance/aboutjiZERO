# 김지영백과사전

빌드 없이 바로 열리는 정적 웹앱이에요 (HTML · CSS · JS).

## 화면

| 파일 | 화면 |
| --- | --- |
| `index.html` | 00 스플래시 (시작 화면) |
| `home.html` | 01 홈 |
| `search.html` | 01-1 검색 |
| `gallery.html` | 01-2 사진 |
| `explore.html` | 02 항목 선택 |
| `birth.html` · `food.html` · `exercise.html` · `philosophy.html` | 03 세부 내용 |

## 로컬에서 보기

`index.html`을 브라우저로 열면 돼요.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 올려요.
2. Vercel에서 **Add New → Project**로 그 저장소를 가져와요.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 비워두고 **Deploy**를 눌러요.
